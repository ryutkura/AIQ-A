# エコーステートネットワークの状態更新式に項が2つある理由

[[エコーステートネットワーク]]（ESN）のリザバー状態更新式は、一般的に次のような形をしている。

$$x(n) = f\big(W^{in} u(n) + W x(n-1)\big)$$

この2つの項は「中間層が次の層と直接リンクしているかどうか」とは無関係。ここが疑問の元だった。

## 二つの項は「空間」と「時間」で別物

普通の順伝播型ネットワーク（[[MLP]]）の中間層は次の形で、項は1つしかない。

$$h = f(W x_{\text{前の層}})$$

理由は単純で、MLPには「時間」という軸がなく、その瞬間の入力だけを見て出力を決めればいいから。

一方ESNのリザバーは、時間方向に自分自身とつながっている（再帰結合）という、MLPには無い軸を持つ。つまりリザバーのノードは、同じ瞬間に2種類の別々の相手から情報を受け取っている。

| 項 | 送り元 | 軸 |
|---|---|---|
| $W^{in}u(n)$ | 入力層（現在時刻 $n$） | 空間方向（層→層） |
| $W x(n-1)$ | リザバー自身（1つ前の時刻 $n-1$） | 時間方向（自己ループ） |

「中間層が次の層に直接リンクしていない」というのはその通りで、実際 $Wx(n-1)$ の項は次の層（出力層）とは何の関係もない。これはリザバーが「出力層に向かう項」ではなく、「自分自身の過去に向かう項」である。出力層への写像は

$$y(n) = W^{out}[u(n); x(n)]$$

という完全に別の式で、状態更新式には登場しない（フィードバック結合 $W^{fb}y(n-1)$ がある構成を除く）。

## この項がないと何が失われるか

もし $Wx(n-1)$ の項がなければ、

$$x(n) = f(W^{in}u(n))$$

となり、各時刻の入力だけから状態が決まる、記憶を持たない普通の順伝播になってしまう。それだと時系列データを扱う意味がない。

$x(n-1)$ の項があるからこそ、過去の入力の影響が $W$ を通じて減衰しながら現在の状態に「こだま（echo）」のように残り続ける。これが Echo State Network の名前の由来そのもの。

時間方向に展開図を描くと分かりやすい。リザバーのノードは「入力層（時刻 $n$）」と「リザバー自身（時刻 $n-1$）」という2つの別々のノード群から矢印を受け取っている形になり、これがMLPの「2つの層から矢印を受ける」のと同じ構造として二項になっている、とイメージすると理解しやすい。

## それって単に「次元が増えた順伝播ネットワーク」なだけでは？

**この疑問は一瞬だけ見れば正しい。** 時刻 $n$ の式だけを静止画として切り取れば、

$$x(n) = f\big([W^{in}, W] \cdot [u(n); x(n-1)]\big)$$

と書けて、これは $u(n)$ と $x(n-1)$ を結合した1本の[[ベクトル]]に、結合した重み[[行列]]をかけているだけ＝「入力次元が増えた普通の順伝播層」と数式的に完全に一致する。ここまでは何も間違っていない。

決定的に違うのは、**$x(n-1)$ の中身が自由な値ではない**という点。普通に次元を増やす場合、追加した次元（例えば気温など）はネットワークの計算と無関係などこかから飛んでくる値。しかしESNの $x(n-1)$ は「1ステップ前に、この全く同じ重み $W^{in}, W$ を使って計算された出力」という制約が掛かっている。

$$x(n-1) = f\big(W^{in}u(n-1) + Wx(n-2)\big)$$

これを $x(n)$ の式に代入し、さらに $x(n-2)$ を代入し…と展開していくと、$x(n)$ は最終的に過去の入力 $u(n), u(n-1), u(n-2), \dots$ すべての関数になる。しかも何ステップ遡っても使われている重みは同じ $W^{in}, W$ の2つだけ（重み共有）。もし本当に「次元を増やしただけ」なら、履歴を10ステップ見せたければ10ステップ分の独立な重みが要るはずだが、[[RNN]]/ESNは同じ2つの重み行列を使い回すことで、パラメータ数を増やさずにいくらでも長い履歴を固定次元の $x(n)$ に圧縮できる。

**たとえ**：スカラーの漸化式 $a_n = r\,a_{n-1} + c$ も1ステップだけ見れば「前の値に係数をかけて定数を足しただけ」だが、展開すると

$$a_n = c(1 + r + r^2 + \dots + r^{n-1}) + r^n a_0$$

という等比数列になり、全過去の $c$ が $r$ のべき乗で減衰しながら現在に効いてくる構造が見える。$Wx(n-1)$ の項も同じで、同じ重みを自分自身に繰り返し適用し続けることで、有限のパラメータ数から長い履歴を圧縮表現できる。これが「次元を1つ増やしただけ」の順伝播ネットワークでは原理的に得られない性質。

## 別々に管理・計算していないのに、なぜ「時系列」として意味を持つのか

活性化関数を外し、リザバーを1ノードだけにした単純な式で実際に展開してみる（$w=0.5$）。

$$x(n) = u(n) + 0.5\,x(n-1)$$

4ステップ展開すると、

$$x(3) = u(3) + 0.5\,u(2) + 0.25\,u(1) + 0.125\,u(0)$$

$x(3)$ という**たった1つの数字**の中に、$u(0), u(1), u(2), u(3)$ 全部が係数 $1, 0.5, 0.25, 0.125$ という減衰する重みで混ざり込んでいる。別々の箱に時刻ごとに分けて保存しているわけではなく、本当に1つの数字に全部が足し合わされて潰れている。にもかかわらず、「新しい入力ほど大きい係数、古い入力ほど小さい係数」という非対称性がそこに刻まれている。この非対称性そのものが「時間の情報」の正体で、時間を意味として理解しているわけではなく、**混ざり方の比率が時間経過と相関している**というだけのこと。

これは特殊なことではなく、コンデンサ（RC回路）の電圧充電と全く同じ数式。コンデンサの電圧は時刻ごとに分けて保存されているわけではなく常に1つの電圧値に全部が混ざり込んでいるが、それでも「さっきの電圧変化は強く反映され、大昔の変化はほぼ消えている」という時間的情報を単一の値が持っている。

線形結合（足し算・重み付き和）は情報を完全に破壊するのではなく「重ね合わせ」として保持する。混ぜた後の数字1つからでも、どの成分が強く効いているかという統計的な痕跡は残っており、出力層 $W^{out}$ はその痕跡（時間的に偏った重み付き和のパターン）を読み取れるように学習で調整される。つまり「時間的な意味」は、(1) $x(n)$ が過去の入力の decay 付き重ね合わせにしかなり得ないという数式上の制約と、(2) その重ね合わせパターンから欲しい情報を線形に取り出せるよう出力層を訓練すること、この2つの組み合わせの結果として現れている。
